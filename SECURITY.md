# Security policy

AvroSharp and its add-on packages decode untrusted data, so malformed input that causes a crash, hang, or excessive memory use is treated as a security issue.

Please report vulnerabilities privately through [AvroSharp's security advisories](https://github.com/AvroSharp/AvroSharp/security/advisories/new) (the repository's **Security** tab, **Report a vulnerability**), rather than in a public issue. Every package, the add-ons included, lives in that repository.

Only the latest released version of each package receives security fixes.
