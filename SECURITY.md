# Security policy

AvroSharp and its add-on packages decode untrusted data, so malformed input that causes a crash, hang, or excessive memory use is treated as a security issue.

Please report vulnerabilities privately through the affected repository's **Security** tab (**Report a vulnerability**), rather than in a public issue. For the core library, that is [AvroSharp's security advisories](https://github.com/AvroSharp/AvroSharp/security/advisories/new).

Only the latest released version of each package receives security fixes.
